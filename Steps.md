# Steps for analisys

You should memorize these steps in order.

---

## Step 1: Domain

- Find the domain of the function

- Write it as an interval

- Add what you found to the drawing

---

## Step 2: Axis Intersections

- Calculate $f(0)$

- Calculate $f(x) = 0$

- With your results, determine the points in which the function touches/crosses the axes and name them point A, B, and so on.

- Add the points you found to the drawing

---

## Step 3: Symmetry

- If Domain or Axis intersections are not symmetrical you can just write "The domain/The axis intersections are not symmetrical, therefore the function is not symmetrical"

- Write the function $f(-x)$ and compare it to $f(x)$ and to $-f(x)$

- Determine wether your function has even symmetry, odd symmetry or no symmetry and write it down

- If you find that the function is symmetrycal, remember to use that information in the next steps (for example when calculating the limits)

---

## Step 4: Sign of the function

- Calculate $f(x) = 0$ and $f(x) > 0$

- Add what you found to the drawing

---

## Step 5: Limits and Asinthotes

- Write the domain again as an interval to help yourself find how many and which limits you need to calculate

- Calculate the limits

- Asinthothes are kinda secondary, I did not remember how to find them when I tried my exam but they were not needed. I will explain them in this repo but you can skip studying these if you are in a hurry

- Usually "Limits and Asynthothes" are considered one step. However, if you choose to skip the asynthothes, I would raccomand writing only "Limits" in the exam as name of the step (obviously)

## Step 6: First derivatives

- Find $f'(x)$

- Find for which values of $x$ $f'(x) = 0$

- Calculate $f'(x) > 0$ and use this to find where the function is increasing/rising and when it's decreasing

- Use the informations you have found to determine the points of **maximum and minimum** of the function

## Step 7: Second derivatives

- Find $f''(x)$
